# Design Engineer Skill

This skill guides Antigravity to craft high-craftsmanship, bespoke web experiences that look and feel like they were designed by top design studios (Linear, Stripe, Apple, Vercel), steering completely clear of cliché "AI-generated" looks.

## Core Directives

### 1. Architectural Foundation
- **Component Primitives**: Always build components using unstyled accessible primitives (Radix UI, React Aria) styled with Tailwind CSS, following the `shadcn/ui` pattern where the user owns the code.
- **Micro-Interactions**: Use `motion` for spring-based layout animations, exits, entries, and gestures.
- **Design Tokens**: Standardize colors on Zinc/Slate with semantic accents (Emerald for success/safety, Amber for warning, Indigo/Rose for bespoke brand highlights). Avoid harsh saturation.

### 2. Sourcing From Open Source Registries
When building components, borrow visual patterns and architectures from top open-source registries:
- **21st.dev ("The npm for Design Engineers")**: Search and emulate the highest-voted interactive cards, command palettes, and animated tabs.
- **Magic UI**: Borrow patterns for dynamic Bento Grids, animated border beams (`border-beam`), and background grain/noise.
- **Aceternity UI**: Implement 3D card perspective tilts, subtle spotlight following cursors, and tracing beams for timelines.
- **Sonner & Vaul**: Emil Kowalski's mobile drawer physics and swipeable stacked toasts.

### 3. Execution Checklist for Any Web Page
Before considering any web page finished, verify:
1. [ ] **No Generic Headings**: Copy reflects the exact domain (e.g. Italian driving regulations, true vehicle dynamics, authentic exam criteria).
2. [ ] **Tactile Press States**: Buttons and cards depress on click (`active:scale-[0.98]`).
3. [ ] **Multi-Layer Lighting**: Ambient subtle borders (`border-white/[0.08]`) paired with soft drop shadows.
4. [ ] **Data Density & Realism**: Tabular figures (`font-mono`, `tabular-nums`), authentic stats, badges, and clean metadata tags.
5. [ ] **Keyboard & Accessibility**: Every primary action is reachable via keyboard shortcuts (e.g., `V` for Vero, `F` for Falso, `Space` for pause/continue).
6. [ ] **Responsive Fluidity**: Flawless mobile viewport adaptation with sticky bottom navigation or drawers.
