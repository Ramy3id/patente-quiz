# Patente B Pro — Modern Web Suite & Design System

مشروع ويب فائق الجودة والواقعية مبني خصيصاً ليجمع بين:
1. **الواقعية الكاملة لبيانات رخصة القيادة الإيطالية (Patente B)**: 30 سؤالاً في 20 دقيقة، 413 صورة إشارة مرورية، ردود أفعال صوتية فيزيائية، وحاسبة مسافات فرملة ديناميكية.
2. **منظومة Antigravity Design Engineering**: تم تزويد المشروع بملف قواعد `GEMINI.md` ومهارة مخصصة `design-engineer` لمنع أي كليشيهات ذكاء اصطناعي ("AI Slop") وضمان خروج أي صفحة جديدة بمظهر وكالات التصميم العالمية (Linear, Stripe, Apple).

---

## 🚀 كيفية تشغيل المشروع (How to Run)

افتح موجه الأوامر (Terminal / PowerShell) في هذا المجلد:

```bash
# 1. الدخول لمجلد المشروع
cd R:\Ramy\PATENTE\patente-modern-web

# 2. تثبيت الحزم (فقط في أول مرة)
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev
```

سيفتح الموقع تلقائياً في متصفحك على: `http://localhost:3000`

## 🛠️ ما الذي تم تثبيته في هذا المجلد؟

1. **`GEMINI.md` (قواعد مهندس التصميم الصارمة)**:
   - يمنع الذكاء الاصطناعي من استخدام تدرجات البنفسجي المبتذلة على خلفيات سوداء.
   - يفرض فيزياء الحركة التفاعلية (`Spring Physics`).
   - يفرض وجود استجابة لمسية للأزرار (`:hover`, `:active`, `:focus-visible`).
   - يمنع نصوص الحشو (Lorem Ipsum) ويفرض نصوصاً واقعية مطابقة للمجال.

2. **`.agents/skills/design-engineer/SKILL.md` (مهارة Antigravity)**:
   - تمكّن Antigravity من جلب واقتباس تصاميم من أفضل السجلات المفتوحة المصدر (`shadcn/ui`, `21st.dev`, `Magic UI`, `Aceternity UI`, `Tremor`).

3. **تطبيق ويب React + Vite + Tailwind CSS فائق السرعة**:
   - محاكاة اختبار حقيقي لـ 30 سؤالاً من ملف `quizPatenteB2023.json`.
   - لوحة تفاعلية (Bento Grid) مع حاسبة مسافة التوقف وسرعة المركبة.
   - بطاقات إشارات ثلاثية الأبعاد تنقلب لكشف الفخاخ الامتحانية.
   - صوتيات لمسية خفيفة باستخدام Web Audio API النظيف بدون أي ملفات خارجية.
   - اختصارات لوحة المفاتيح: اضغط `V` لـ Vero و `F` لـ Falso أثناء الاختبار.
