# أرشيف سكريبتات معالجة الباب الثامن ومذكرات الاستخراج
## Historical Chapter 08 Processing & Migration Scripts

يحتوي هذا المجلد على سكريبتات Python ومذكرات استخراج نصية استُخدمت أثناء مرحلة ترجمة ومراجعة وتدقيق **الباب الثامن (Segnali di Indicazione)**:
1. `apply_ch08_batch_9.py` إلى `batch_13.py`: قواميس ترجمة الأسئلة المعتمدة باللغة العربية مع الشروحات القانونية والأفخاخ والكلمات المفتاحية.
2. `audit_ch08.py` و `sync_*.py` و `fix_ch08_keywords.py`: أدوات التحقق من اكتمال الحقول ومزامنة بيانات الأسئلة بين `domande.json` والملفات المستهدفة.
3. `extracted_*.txt`: مذكرات استخراج نصوص وملاحظات مرحلية.

تم نقل هذه الملفات من المجلد الرئيسي (Root) إلى هذا الأرشيف للحفاظ على نظافة وهيكلية المستودع دون حذف أي أثر برمجي أو تاريخي.
